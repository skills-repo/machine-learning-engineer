# ML 实验记录模板

> 每次实验填一份。最小成本换最大可复现性。复制后用，不提交到仓库也可。

## 实验元信息

- 实验名 / 编号：
- 日期：
- 目标（要验证什么假设）：
- Git commit：
- 数据版本（哈希/标签）：

## 配置

- 模型结构：
- 关键超参：
- 随机种子：
- 环境与依赖版本（lockfile / 镜像）：

## 数据

- 训练集：路径 / 行数 / 切分方式（含种子）
- 验证集 / 测试集：
- 预处理：是否用到标签、是否全量统计（防泄漏）

## 产物

- 权重路径：
- 日志 / 曲线：
- 失败观察 / 异常：

## 结论

- 相对基线是否提升、提升是否显著：
- 下一步（控制变量改什么）：
- 是否达到上线门槛（标注离线↔业务鸿沟）：
